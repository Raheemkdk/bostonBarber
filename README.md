# 💈 Boston Barber — Warren Street Barbers

A modern, Boston-inspired barbershop landing page built using **HTML5 and CSS3**.

This project showcases frontend web development skills through a clean, business-focused website for **Warren Street Barbers**, a fictional neighborhood barbershop concept based in Roxbury, Massachusetts.

Live Link: boston-barber-web.netlify.app

## 🌟 Project Overview

<img width="942" height="490" alt="image" src="https://github.com/user-attachments/assets/6159ae5b-16cd-46d0-b8b3-62a180987eaf" />

Boston Barber is a static website designed to showcase a barbershop's services, pricing, business information, and brand identity.

The project focuses on creating an organized, visually appealing landing page that helps customers quickly find essential information about the shop.

It demonstrates foundational frontend development concepts, including semantic HTML, CSS styling, navigation, tables, and image integration.

## ✨ Features

- **Business landing page:** A welcoming homepage with the headline "Fresh Cuts. No Waiting."
- **Navigation menu:** Includes Home, Prices, About, and Contact links.
- **Service pricing table:** Displays haircut services and their prices.
- **Booking call-to-action:** Features a "Book a Chair" button.
- **About section:** Introduces the barbershop's personality and neighborhood identity.
- **Image integration:** Displays a barbershop image with a caption.
- **Business information:** Includes an address, phone number, and operating hours.
- **Custom CSS:** Provides a consistent visual design.

*Note: The navigation links are currently placeholders, and the booking button does not have a functional booking integration.*
